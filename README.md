## Условные обозначения

- `📌` — закреплённое сообщение
- `📎` — приложенный файл
- `🖼️` — фото
- `↪` — ответ на сообщение (с цитатой и навигационной ссылкой)
- `↗` — открыть оригинал в Telegram (для просмотра реакций, скачивания файла, доступа к контексту)
- `*(ред.)*` — сообщение было отредактировано
- **Админ** — анонимный пост от имени канала

## Файлы и скачивание

Сами файлы (PDF, ZIP, фото) в репозитории **не хранятся**. Каждое сообщение и каждое вложение содержит ссылку `↗` на оригинальный пост в Telegram-группе `@daggerheart_ru`. Перейдя по ссылке, можно: скачать файл, посмотреть реакции, прочитать обсуждение вокруг.

## Что не вошло

- Системные сообщения (вступления, изменения названий, опросы)
- Реакции
- Сами медиа-файлы (только пометки + ссылки на оригиналы)
